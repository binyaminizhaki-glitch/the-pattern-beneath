# Cinematic game — 17 November 2026

The game keeps its original artwork and simulation. It replaces forced readings and weekly encounters with a timed opening and an uninterrupted, two-choice turn loop. The five-page reading version has been superseded.

Visual thesis: a dark painted room leads into a living town; images and recorded movement carry the experience. Content order: title, four quotes, one bridge line, eight player-controlled weeks, comparison, closing room. Motion: slow camera movement over the room, quiet shot arrivals, and the existing seven-phase projection of actual model decisions.

## Town and results

Each of the two action buttons invokes exactly one engine step with its narrative and `channel: 'gazette'`. The existing engine, three-channel capability, 48 agents, eight weeks, keyed randomness, immutable snapshots, access decisions and manuscript requirements are unchanged. Other channels and quiet play are not part of the current player controls.

The seven visual phases retain the existing 4.2 seconds of scheduled time. Duplicate input is locked. Skip finishes presentation without replaying a step. No automatic conversation, room task, midpoint dialog, event text bubble or next-week action occurs. The default HUD contains only week and weekly publication counts; record details appear only on request.

Phones use a larger horizontal town camera with native swipe and arrow controls, preserving a readable scene. Records provide a native citizen selector when individual map targets are too small. The scene remains playable without sound.

The ending compares cumulative women's publications for weeks 1–8 against the no-message run with the same seed and chance events. The opening edition is excluded. Optional details distinguish recorded counts, the editor's interpretation and fictional model assumptions. Continue returns to the room, the original engraving and a verified ending excerpt. Play again resets the world and timer state while keeping the session's sound preference. No mental-health state or causal claim is added.
