# Project rules

Use strict TypeScript and pure simulation functions. Never mutate prior snapshots or base aptitude. Derive metrics from individual state and recorded decisions. Every publication must have a manuscript and access record. Use keyed per-agent/event randomness; no Math.random in the engine.

Keep product text in English. Preserve the distinction between measured outputs, editorial inference and fictional model assumptions. No diagnostic mechanics, backend or external runtime APIs.

Run `npm run test`, `npm run build` and `npm run test:e2e` after material changes. Inspect desktop/mobile screenshots. Do not deploy or push without permission.

Use Headroom/RTK when available. Report unavailable wrappers and use bounded output rather than blocking implementation on tooling.
